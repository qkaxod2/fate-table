# 외부 스킬 출처

아래 스킬은 외부 저장소에서 그대로 복사했다. 업데이트할 때는 같은 경로에서 다시 복사한다.

| 스킬 | 저장소 | 커밋 | 라이선스 |
| --- | --- | --- | --- |
| threejs-* (9종) | https://github.com/majidmanzarpour/threejs-game-skills (`skills/`) | 8286774 | MIT |
| logo-design | https://github.com/kaankiziltug/logo-design-skill (`skills/logo-design`) | e9eaddc | MIT |
| ponytail, ponytail-* (6종) | https://github.com/DietrichGebert/ponytail (`skills/`) | ebd8654 | MIT |

ponytail은 스킬 파일만 가져왔고, 저장소의 hooks(상태줄, 세션 훅 등)는 설치하지 않았다.
threejs-3d/audio/image-generator는 각각 TRIPO_API_KEY, ELEVENLABS_API_KEY, GEMINI_API_KEY가 있어야 동작한다.
