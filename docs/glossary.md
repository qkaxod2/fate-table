# 용어집 (입문자용 명사 로컬라이징)

원칙: 처음 보는 사람도 뜻을 짐작할 수 있는 짧은 명사. 툴 안의 모든 표기는 이 파일 하나를 기준으로 함(구현 시 glossary 데이터로 관리).

## 캐릭터
| 원어 | 툴 표기 | 한 줄 설명 (툴팁) |
|---|---|---|
| Aspect | **특성** | 캐릭터나 장면을 설명하는 짧은 문구. 유리하게도, 불리하게도 쓰임 |
| High Concept | **핵심 컨셉** | 캐릭터를 한 줄로 요약한 특성 |
| Trouble | **약점** | 캐릭터를 곤란하게 만드는 특성 |
| Approach | **접근법** | 행동하는 방식. 6가지 |
| Careful | **신중** | 꼼꼼하게, 조심스럽게 |
| Clever | **지략** | 머리를 써서 |
| Flashy | **화려** | 눈에 띄게, 멋지게 |
| Forceful | **완력** | 힘으로 밀어붙여서 |
| Quick | **신속** | 빠르게 |
| Sneaky | **은밀** | 몰래, 속여서 |
| Stunt | **특기** | 특정 상황에서 보너스를 주는 고유 능력 |
| Fate Point | **운명점** | 특성을 발동할 때 쓰고, 강요를 받아들이면 얻는 점수 |
| Refresh | **재충전** | 세션 시작 시 운명점이 채워지는 기준값 |
| Stress | **스트레스** | 가벼운 피해를 막는 칸 3개 |
| Consequence | **후유증** (경상 2 / 중상 4 / 중태 6) | 큰 피해를 받아낸 대가로 남는 특성 |
| Milestone | **이정표** | 성장 시점 (소·중·대) |

## 판정
| 원어 | 툴 표기 | 설명 |
|---|---|---|
| Fate Dice (4dF) | **페이트 주사위** | +, −, 빈 면이 있는 주사위 4개 |
| The Ladder | **등급표** | 결과 수치를 말로 표현한 표 |
| Overcome | **극복** | 장애물을 넘음 |
| Create an Advantage | **이점 만들기** | 새 특성을 만들거나 찾아냄 |
| Attack | **공격** | 피해를 줌 |
| Defend | **방어** | 공격·방해를 막음 |
| Fail / Tie / Succeed / Succeed with Style | **실패 / 동점 / 성공 / 대성공** | 대성공은 3 이상 차이 |
| Invoke | **발동** | 운명점 1로 +2 또는 다시 굴림 |
| Free Invoke | **무료 발동** | 운명점 없이 한 번 쓰는 발동 |
| Compel | **강요** | 약점 등으로 일이 꼬이는 대신 운명점을 받음 |
| Boost | **부스트** | 한 번 쓰면 사라지는 임시 특성 |
| Situation Aspect | **장면 특성** | 장면이나 구역에 붙은 특성 |
| Shifts | **차이** | 결과와 난이도의 차이 |

## 장면 진행
| 원어 | 툴 표기 |
|---|---|
| Conflict | **갈등** (전투처럼 서로 해치려는 상황) |
| Contest | **경합** (먼저 3번 이기는 겨루기) |
| Challenge | **도전** (여러 번의 극복으로 푸는 상황) |
| Exchange | **라운드** |
| Concede | **항복** |
| Taken Out | **탈락** |
| Zone | **구역** |

## 등급표
| 수치 | 표기 |
|---|---|
| +8 | 전설 |
| +7 | 서사 |
| +6 | 환상 |
| +5 | 최상 |
| +4 | 우수 |
| +3 | 양호 |
| +2 | 준수 |
| +1 | 보통 |
| +0 | 평범 |
| −1 | 미흡 |
| −2 | 최악 |

등급표 접근법 기본 분배: 양호(+3) 1개, 준수(+2) 2개, 보통(+1) 2개, 평범(+0) 1개.
